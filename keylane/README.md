# Keylane · 2FA 验证器

紫色玻璃风格的浏览器端验证码工具。无需依赖、构建或后端。

## 功能

- Base32 密钥生成 TOTP 验证码：SHA-1、6 位数字、30 秒周期。
- 自动刷新、到期提醒、一键复制，以及剪贴板兼容处理。
- 可选记住上次有效密钥，输入错误不会覆盖已保存的有效密钥。
- 支持显示/隐藏、清空；切换到其他页面时自动隐藏密钥。
- 适配手机，支持减少动画与降低透明度偏好。

## 打开方式

在线使用：将本目录部署到 HTTPS 静态托管即可。若此仓库的 GitHub Pages 从 main 分支根目录发布，本页路径为 `/keylane/`。

本地开发：在本目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。

单文件版：下载 `standalone.html` 后用现代浏览器打开，CSS 和脚本均已内嵌。通过文件地址使用时，浏览器对存储和剪贴板的支持可能有所不同。

## 文件

- `index.html`：页面结构。
- `style.css`：响应式玻璃样式。
- `app.js`：保存、复制、状态反馈和自动刷新。
- `totp.mjs`：Base32 解码与 TOTP 算法。
- `standalone.html`：可直接下载使用的单文件版本。
- `tests/regression.mjs`：算法与交互逻辑回归测试。

## 测试

使用 Node.js 22 或更新版本运行：

```sh
node tests/regression.mjs
```

覆盖 RFC 6238 的六组 SHA-1 测试向量，以及恢复、保存、清空、错误输入、周期切换、复制兼容处理、存储失败提示等交互逻辑。浏览器视觉效果尚未通过自动化浏览器测试。

## 本地保存说明

密钥只在当前浏览器中计算，可选择保存在该网站的 localStorage 中，不上传到 GitHub 或服务器。此存储不提供额外加密，也不会跨设备同步。请只在自己信任的设备上开启记忆功能，并保持设备时间准确。

此目录独立于仓库原有的 2FA 页面与博客。
