# Keyroom · 2FA 验证码

苹果玻璃风格的纯静态 TOTP 工具，适配手机和桌面。

## 功能

- Base32 密钥或 otpauth://totp/ 链接输入
- SHA-1、SHA-256、SHA-512，6 / 8 位验证码
- 自动刷新、倒计时、一键复制和点击反馈
- 可选记住上次密钥，清除按钮删除本地记录
- 无登录、无后端、无第三方依赖

## 使用

将本目录的 index.html、style.css 和 app.js 部署到 HTTPS 静态托管服务。开发时可在本目录运行 `python -m http.server 8000`，访问 `http://localhost:8000`。Web Crypto 要求 HTTPS 或 localhost 安全上下文。

## 数据保存

密钥只在浏览器中处理。勾选“记住上次密钥”时，密钥及设置保存在当前站点的 localStorage 中，不加密、不跨设备同步；取消勾选或点击“清除”可删除记录。演示使用公开测试密钥，不会覆盖已保存的真实密钥。本仓库不含用户输入的密钥。

## 验证

核心算法通过 SHA-1 / SHA-256 / SHA-512 标准 TOTP 测试向量；已进行生成、复制、错误提示、保存、刷新恢复和清除的浏览器检查。

## 文件

- index.html：界面
- style.css：玻璃样式、响应式布局和交互动画
- app.js：TOTP 计算、交互和本地保存
