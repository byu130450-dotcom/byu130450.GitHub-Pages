# 一页之间 · 个人博客

公开阅读的个人博客，配有仅站点所有者可使用的写作后台。

- `/`：文章、分类、搜索、归档及关于页面
- `/admin`：通过 ChatGPT 登录，写文章、保存草稿、预览、发布与撤回
- `/api/posts`：仅返回已发布文章；未开始写作时展示明确标注的示例
- `/api/admin/posts`：服务端验证管理员身份和记录归属

文章保存在 Cloudflare D1。编辑采用版本号，防止多窗口互相覆盖。正文为纯文本，空行分段，`## ` 表示小标题，不执行 HTML。

管理员邮箱由运行时 secret `BLOG_ADMIN_EMAIL` 配置，不能从浏览器输入或从请求正文指定。认证由 Sites 提供。公开访客无需登录；写作必须使用站点所有者账号。

## 开发

遵循 Sites 技能的安装、构建和发布流程。修改数据结构后运行 `npm run db:generate`，生成并提交迁移。运行 `node scripts/test-blog.mjs` 验证匿名/管理员权限、草稿保密、保存、发布、撤回与版本冲突。

本地与生产数据库分离。不要提交运行时密钥或 `.dev.vars`。

## GitHub 中的源码

此目录保存博客与写作后台的完整源码。现有线上博客由 Sites 托管。后台使用服务端身份验证和 D1 数据库，不能直接作为纯静态 GitHub Pages 网站运行。运行时管理员密钥和实际数据库内容不包含在仓库中。
